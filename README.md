# Orange Lab – Inventory & Purchasing
برنامج متابعة **المخزون (الجرد) والمشتريات** لمعمل Orange – فرعي دايموند ولاسيتي.
مبني بـ Python / Streamlit (نفس أسلوب برنامج الزيارات وبرنامج الأسعار).

---

## 1) دورة العمل في سطر واحد

```
الجرد  →  النواقص  →  طلب شراء (PDF / واتساب باسم ورقم الشركة)  →  الاستلام = فاتورة (كيت · لوت · صلاحية)  →  الدفع  →  التقارير
```

| الصفحة | بتعمل إيه |
|---|---|
| 🏠 Dashboard | النواقص، الصلاحيات المنتهية/القريبة، الطلبات المفتوحة، المستحق للشركات، مصروف الشهر، آخر جرد لكل فرع |
| 📋 Inventory count | إدخال الجرد بنفس شكل الشيت (مستلزمات / كيماويات) + تاريخ الجرد + المخزون الحالي والصلاحيات |
| 🛒 Shortages → order | يجمع اللي عليه **B** من آخر جرد (+ احتياجات يدوية) ويطلع **طلب لكل شركة** |
| 📨 Purchase orders | فورمة الطلب PDF (نفس فورمتكم) + زرار واتساب على رقم الشركة + استلام الطلب |
| 🧾 Purchases & payments | الفواتير/التوريدات: الصنف، البراند، نوع الكيت، اللوت، الصلاحية، السعر، المرتجع، الدليفري، الدفع ومتى |
| 🏢 Suppliers | أسماء وأرقام الشركات + الرصيد + كشف حساب PDF/Excel |
| 🧪 Items catalog | قائمة الأصناف الموحدة + الحد الأدنى + كمية إعادة الطلب + تاريخ الأسعار |
| 📊 Reports | سجل المشتريات Excel/PDF (زي ملفكم السنوي)، كشف الحساب، الجرد، الصلاحية، تحليل المصروف |
| ⚙️ Settings | بيانات المعمل والفروع والتوقيعات، نسخ احتياطي/استرجاع، استيراد ملف المشتريات القديم، سجل الحركات |

## 2) أساس نظام إدخال الجرد

* **سطر لكل براند / لوت**: نفس الصنف ممكن يتكرر (مثلاً ALT: Agappe في الـ Active و Genesis في الـ Stock).
* **Active** = المفتوح / اللي شغال على البنش · **Stock** = المخزّن غير المفتوح. لكل واحد كمية + وحدة + صلاحية.
* **Br**: ‏D = دايموند، L = لاسيتي، D&L = مشترك (زي صبغة الفيلم).
* **الصلاحية MM/YYYY** (مثال 11/2026، أو 2029 لوحدها = 12/2029). أي كتابة غلط البرنامج يوقف الحفظ ويقول السطر.
* **Status**: ‏Auto (البرنامج يقرر) · G · B · ‏- (مش مستخدم في الفرع ده).
* **ألوان الشيت محفوظة**: متاح أسود · منتهي أحمر · كمية قليلة أزرق · غير متاح أخضر – وتطلع في الـ PDF بنفس الشكل.
* **قاعدة البرنامج للـ B**: لو مفيش كمية، أو كل اللوتات منتهية، أو الكمية ≤ الحد الأدنى للصنف.
  لو الشيت كاتب G والبرنامج شايف B بيكتب جنبها صغير **app: B** – عشان ما يفوتش صنف منتهي متعلّم G.
* **بداية الجرد**: «انسخ آخر جرد» (تعدّل اللي اتغير بس) أو شيت فاضي من الأصناف أو **رفع Excel** (فيه Template جاهز في فولدر `templates/` وكمان بيتنزّل من البرنامج).

## 3) المشتريات والدفع

* نوع السطر: **Purchase / Return (مرتجع بيتخصم) / Free / Gift**، وخصم % على السطر، ودليفري وخصم على الفاتورة.
* الدفع: أكثر من دفعة لكل فاتورة (Vodafone Cash / InstaPay / Cash / تحويل / شيك) بتاريخها ← الحالة Paid / Partial / Unpaid تلقائي.
* استلام طلب شراء ← الفاتورة بتتعمل جاهزة بالأصناف وآخر سعر، وتحدّث حالة الطلب (Received / Partially received).
* سجل المشتريات Excel بنفس فكرة ملفكم (بلوك لكل فاتورة + سطر إجمالي فيه الدفع وتاريخه) **بمعادلات شغالة**، + شيتات: كل السطور، المدفوعات، حسب الشركة، حسب الشهر، حسب النوع.

## 5) التشغيل

### على الجهاز
```bash
pip install -r requirements.txt
streamlit run app.py
```
أو دبل كليك على `run_windows.bat`.

### على Streamlit Cloud (مع حفظ دائم في GitHub – نفس طريقة برنامج الزيارات)
1. ارفع الفولدر على GitHub.
2. في Secrets حط محتوى `.streamlit/secrets.toml.example` بعد تعديل الباسوردات والـ token.
3. أول مرة: ملف البيانات `data/inventory_db.json` يتحط في المسار اللي في `[github] path` (أو سيبه والبرنامج يبدأ فاضي).

* كل حفظ = يقرأ آخر نسخة ← يطبّق التعديل ← يحفظ. لو الفرعين حفظوا في نفس اللحظة البرنامج يعيد المحاولة ويدمج (مفيش تعديل يمسح التاني).
* لو الحفظ فشل بيظهر **❌ NOT SAVED** واضح.
* البرنامج ما بيقراش GitHub مع كل ضغطة – بس عند الدخول وزرار 🔄 Refresh وقبل كل حفظ.

### الدخول
باسورد واحد للموظفين وباسورد للأدمن (في Secrets). الافتراضي لو مفيش Secrets: `orange` / `orange-admin` – **غيّروه**.
الأدمن بس: الإعدادات، الحذف، الاسترجاع، الاستيراد.

## 6) اقتراحاتي للمرحلة الجاية

1. **ربط الاستهلاك بالتحاليل**: كل كيت له «عدد تحاليل»؛ برنامج الأسعار/الزيارات يبعت عدد التحاليل المعمولة ← المخزون ينزل لوحده بين الجردين، والنواقص تطلع قبل ما الصنف يخلص.
2. **تكلفة التحليل (Cost per test)** من سعر الكيت ÷ عدد التحاليل، ومقارنتها بسعر التحليل في برنامج الأسعار (هامش الربح لكل تحليل).
3. **مقارنة أسعار الشركات** لكل صنف من تاريخ الأسعار + تنبيه لو السعر زاد عن آخر مرة.
4. **FEFO**: تنبيه «استخدم اللوت الأقرب انتهاءً الأول» عند فتح كيت جديد.
5. **تقرير واتساب أسبوعي** للمدير: النواقص + اللي هينتهي خلال 60 يوم + المستحق للشركات.
6. **موافقة المدير** على طلب الشراء فوق مبلغ معين قبل الإرسال.
7. **صورة الفاتورة** تترفع مع كل توريد (أرشيف).
8. **باركود/QR للّوت** عند الاستلام، والجرد بالموبايل بالمسح.
9. **ميزانية شهرية** للمشتريات مع مقارنة الفعلي.
10. **تحويل بين الفرعين** (صنف ناقص في فرع وموجود في التاني: «يوجد في السيتي») كحركة مسجلة بدل ملاحظة.

## 7) هيكل الملفات

```
app.py                  الدخول والقائمة
core/config.py          الثوابت والإعدادات الافتراضية
core/storage.py         الحفظ (ملف محلي أو GitHub) + الدمج عند الحفظ المتزامن
core/logic.py           قواعد الصلاحية والحالة والنواقص والفواتير والأرصدة
core/pdf_reports.py     PDF: طلب الشراء، الجرد، سجل المشتريات، كشف الحساب، الصلاحية
core/excel_reports.py   Excel: سجل المشتريات، الجرد، Template الإدخال، كشف الحساب، نسخة كاملة
core/importers.py       استيراد ملف المشتريات القديم + Template الجرد
core/arabic.py          كتابة العربي صح في الـ PDF
core/seed.py            الأصناف والجردين من ملفاتكم
ui/page_*.py            صفحات البرنامج
data/inventory_db.json  قاعدة البيانات (JSON)
templates/              Excel جاهز للجرد (مستلزمات دايموند / كيماويات الكل)
samples/                أمثلة مخرجات (طلب شراء، جرد، سجل مشتريات، كشف حساب)
```
